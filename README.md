# Kraina Pupila – strona salonu

Jednostronicowa strona salonu pielęgnacji psów **Kraina Pupila** (Maków Podhalański).
Jeden plik `index.html` – bez budowania, bez zależności. Otwórz w przeglądarce albo włącz GitHub Pages (Settings → Pages → branch → `/root`).

## Do uzupełnienia / sprawdzenia
- godziny otwarcia (teraz: „po wcześniejszym umówieniu”)
- cennik (teraz: wycena telefoniczna)
- zdjęcia w `img/` są wycięte ze screenów Instagrama (ok. 350×460 px) – oryginały w pełnej rozdzielczości będą ostrzejsze
- baner urlopowy znika sam po 4.10.2026 (skrypt na dole `index.html`)
- zakres usług – czy wszystkie 6 kafelków się zgadza
